# WeightLang

**A programming language for building neural networks.**

WeightLang is an early-stage concept for describing neural networks and producing runnable weights on top of PyTorch. It is intended to be written primarily with the help of AI coding models.

We want to make weights reusable and shareable through packages addressed by GitHub repositories, drawing inspiration from Go's package distribution model.

- Language files: `.wgt`
- Planned compiler: `weightc`
- Backend ecosystem: PyTorch
- Status: concept — the language, compiler, and package manager do not exist yet.

See the [main repository](https://github.com/WeightLang/WeightLang) for the concept and proposed next steps.
